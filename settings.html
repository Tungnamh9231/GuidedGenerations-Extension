Prompt Manager Edit every prompt of the extension and choose where each one is sent.

Opens a SillyTavern-style prompt list. The native prompts are display-only and mirror SillyTavern's own Prompt Manager 1:1 (same order, state and edits) — reorder, toggle or edit them there. The prompts of this extension's features are blocks that can be edited but never deleted or disabled. Drag a block between the native prompts to decide where that feature's prompt is sent, with which role, depth and order. Features that own more than one prompt get one tab per prompt, plus a reset button; the guide Raw flag and injection Depth live in that edit form.
